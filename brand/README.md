# Brand assets

These are the official Opificia AI logo files. They are copied unchanged from the Opificia AI brand book (the design system that defines the logo, colours and voice). Do not edit them.

The files in this folder are **not open source**. You may use them only as described in [`TRADEMARKS.md`](../TRADEMARKS.md). This README is licensed under CC-BY-4.0.

## Which file to use

| File | Use it for |
| --- | --- |
| `opificia-lockup.svg` | The default logo, on white and other light grounds. |
| `opificia-lockup-reverse.svg` | Navy and other dark grounds, and dark themes. |
| `opificia-lockup-stacked.svg` | Square or tall spaces, such as posters and title slides. |
| `opificia-mark.svg` | Small spaces on light grounds, where the full lockup does not fit. |
| `opificia-mark-reverse.svg` | Small spaces on navy or dark grounds. |
| `opificia-favicon.svg` | Below 24px: browser tabs and other very small sizes (16 to 32px). |
| `opificia-avatar.svg` | The GitHub organisation and social media profiles. Crop to a circle. |
| `opificia-app-icon.svg` | App and touch icons. |

## Size and spacing

- **Minimum size:** the lockup 120px wide on screen; the mark 24px. Below 24px, use the favicon.
- **Clear space:** keep a quarter of the mark's height free on every side. No text, edges or other logos inside it.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Navy | `#10194A` | The brand colour: the mark, headlines, large fields. |
| Gold | `#F2B705` | The signal: the twelfth tooth and at most one highlight per view. Never as text on light grounds. |
| White | `#FFFFFF` | The main ground. |
| Mist | `#EEF1F7` | Alternating sections, code blocks. |
| Slate | `#4A5275` | Secondary text and metadata. |

## Rules in short

- Never redraw, recolour, rotate, stretch or retype the logo.
- The gold tooth always sits at one o'clock.
- Never make several or all twelve teeth gold. On blue, that reads as the EU emblem, and Opificia is not an EU institution.
- Do not place the default lockup on mid-tone or busy backgrounds; use the reverse version instead.

The full rules are in the [Opificia AI brand book](https://claude.ai/artifact/KFhvKPyUCiUBzaCPtVQ34U) (not public yet; only maintainers can open it for now) and in [`TRADEMARKS.md`](../TRADEMARKS.md). Contact <hi@opificia.ai> for any use not covered here.
